# Photographic materials and lighting

Bundled 1k assets from [Poly Haven](https://polyhaven.com/license), licensed CC0.

* [Industrial Sunset 02](https://polyhaven.com/a/industrial_sunset_02): HDR illumination.
* [Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02): diffuse, roughness and OpenGL normal maps.
* [Wood Planks Grey](https://polyhaven.com/a/wood_planks_grey): diffuse, roughness and OpenGL normal maps.

`provenance.json` records source URLs, exact bytes, and SHA256. No image was generated or modified. These are material references, not photographs of RuLab. The browser loads only bundled same origin files. Run `python rulab/scripts/fetch-graphics.py` from the repository to reproduce assets; unit tests verify the committed bytes without network access.
