# RuLab visual references

These four JPEGs were supplied for the RuLab concept demonstration. They illustrate robotics, hospitality, healthcare and RF environments. They are architectural concept references, not a calibrated photogrammetry dataset or evidence of an operating facility.

| Asset | Role |
| --- | --- |
| robotics.jpeg | Robotics environment thumbnail and explicit reference fallback |
| hospitality.jpeg | Hospitality environment thumbnail and explicit reference fallback |
| healthcare.jpeg | Healthcare environment thumbnail and explicit reference fallback |
| rf.jpeg | RF bay reference retained with the concept assets |

The Three.js meshes and Gaussian primitives are authored separately. The images are not converted into measured 3D geometry by this application. The project code license does not independently establish redistribution rights to user supplied imagery.
